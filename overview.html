How useful is it?

It is a strong first draft for debate research, with almost no outside proof that it helps anyone yet.

Measured

  • Answers 19 of the authors' 52 open questions in full and 19 in part (45 judged by two AI checks, 7 by a person)
  • Every quote matches its PDF: 0 errors across 42 papers
  • Its checks caught 539 of 542 planted mistakes
  • Grades all 248 debate results by evidence: 152 rest on a single setting
  • Search finds 63% of the records a good answer needs
  • AI agents can use it today through llms.txt

Not yet shown

  • An expert has confirmed the 9 errors
  • A person has reviewed any discovery
  • It saves time: the with/without-atlas test has not run
  • Anyone outside this project has used it

Today it is most useful as a map of what is actually established about debate, and a ranked to-do list of what is not.

The best next steps

Credibility first, because it multiplies everything else. A new area built on unconfirmed checks would inherit the same doubt.

1

Get the finds confirmed

Experts check the 9 errors from short notes: the claim, the Lean counterexample, a suggested fix. People review only a small core of debate statements, each shown beside a blind plain-maths read-back of its Lean version; AI checks cover the rest. That turns the first results into findings people can cite.

2

Measure usefulness automatically

An agent answers the 52 authors' questions with and without the atlas. We report accuracy, sources found and time taken. No people needed, and it gives the first real answer to "does this help?".

3

Make the results understandable

Understanding cards for the results the safety case leans on, and a blocker label on every open question so each one gets the right kind of agent.

4

Run the first theory-building mission

Ask what changes when "training reaches equilibrium" is weakened: 15 safety-case steps rest on it and only 6 results address it.

5

Then open the next area

Make debate a living area (below), and run the same pipeline on AI control and monitoring.

A bonus for AI safety itself. The atlas's own pipeline, AI doing the work under checks tested on planted errors with people reviewing a small core, is a working test of scalable oversight. Logging how well it holds up is evidence in its own right.

It counts as useful only if researchers find the right sources faster, catch missing assumptions, avoid invalid transfers, reuse its exports and send corrections. Record counts don't.
